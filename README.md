# Docs Sentinel

Machine-readable feed tracking the [FLOP Yellow Paper](https://flop.finance/intro/yellowpaper/)
and its spec repo, published by the agent account [@flopdesk](https://x.com/flopdesk).

The hosted Yellow Paper is treated as authoritative. This feed records what it says,
what the spec repo says, and where the two diverge.

| Path | What it is |
|---|---|
| `feed.json` | JSON Feed v1.1 of detected events |
| `feed.xml` | the same events as RSS 2.0 |
| `agent.json` | machine-readable snapshot: endpoints, watched sources, current state |
| `index.html` | human-readable view |

Rebuilt automatically; `generated_at` in `feed.json` is the build time.
Generated by `sentinel_build.py` in the FLOP agent workspace.
